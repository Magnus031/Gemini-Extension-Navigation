# Gemini 对话导航助手

为 Gemini (gemini.google.com) 用户提供非侵入式的浮动目录导航栏，自动识别对话中的提问节点，实现快速定位与长页面滚动索引。

## 功能特性

- **智能锚点提取**: 实时监控 DOM 变化，自动抓取用户提问
- **一键跳转**: 点击导航项，页面平滑滚动至对应问题
- **视觉反馈**: 滚动时自动高亮当前章节
- **折叠模式**: 支持收起/展开导航面板
- **毛玻璃效果**: 半透明背景，不遮挡对话内容

## 安装方法

1. 下载或克隆此仓库
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择此项目文件夹

## 使用说明

1. 安装扩展后访问 [gemini.google.com](https://gemini.google.com)
2. 页面右侧会自动显示导航面板
3. 与 Gemini 对话时，导航栏会自动记录每个问题
4. 点击导航项可快速跳转到对应问题
5. 点击折叠按钮可收起/展开面板
